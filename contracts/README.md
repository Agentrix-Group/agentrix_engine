# Contracts (staging reference)

`game.schema.json` is a copy of the authoritative schema from
`github.com/F4nk1/Agentrix`, `contracts/game.schema.json`, pulled on
2026-09-17 for local validation of `games/starfighter/manifest.yaml`
during the Fase 2 staging work in this repository.

This is **not** the source of truth. When `games/starfighter/` is moved
into the real Agentrix monorepo (Fase 7 of the adaptation plan), this
copy should be deleted and the manifest validated against the real
`contracts/game.schema.json` there instead.
